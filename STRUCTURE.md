# PATRON — одностраничник

Next.js 16 / React 19. Стиль: фирстиль PATRON (BBH Bartle + Golos Text, палитра #000 / #FFF / #001948 / #00375E / #A1BAE4),
конструкция — по референсу larnilane.com.

## Где что лежит

- `content/patron/` — тексты действующего интерфейса; карта файлов и правила редактирования: `content/patron/README.md`
- `app/page.tsx` → `app/components/patron/PatronPage.tsx` — действующая страница и её компоненты
- `app/lib/content.ts`, `app/lib/ui-texts.ts`, `app/components/PatronHome.tsx`, `app/components/Hero.tsx` — прежняя реализация; текущая главная страница их не использует
- `app/api/lead/route.ts` — приём заявок с формы
- `public/patron/cases/` — фото кейсов (вытащены из презентаций и переведены в фирменный сине-монохромный дуотон)
- `_backup/` — предыдущая версия страницы

## Структура страницы

1. Hero — «Событие — часть стратегии», фирменная анимация, переход к заявке и кейсам
2. 01 О нас — манифест, 3 принципа и цифры
3. 02 Услуги — 5 направлений: Стратегия / Креатив / События / Продакшн / Аналитика
4. 03 Кейсы — День танкиста 2017, WG Fest 2017, Holiday Ops 2019
5. 04 Процесс — 6 этапов, включая параллельную коммуникацию
6. 05 Заявка — формат, количество гостей, контакты и задача
7. Футер, настройки города и cookies; модальные окна кейсов, этапов и заявки

## Заявки

Без настроек заявки пишутся в лог сервера. Чтобы получать их в Telegram, создайте `.env.local`:

```
TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_CHAT_ID=-100123456789
```

## Запуск

```bash
npm run dev   # http://localhost:3000
```
